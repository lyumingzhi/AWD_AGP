# Local Checkpoints

Put Google Drive checkpoint downloads here using the paths listed in
`configs/weights_manifest.json`. This directory is ignored by git except for
this README.

Examples:

```text
weights/MAT/pretrained/Places_512_FullData_real.pkl
weights/FcF_Inpainting/G.pt
weights/DBWEModel/27kpng_model_best.pth.tar
weights/SLBR/model_best.pth.tar
```
